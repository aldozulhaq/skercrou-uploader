Privacy Policy — Skercrou Uploader

Effective 5 October 2026

Skercrou Uploader ("the tool") is a private command-line tool that uploads videos to the owner's own YouTube channel. It uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • An OAuth 2.0 access and refresh token for the signed-in Google account, with the scopes youtube.upload and youtube.readonly.
  • The signed-in user's own channel information and own videos (ID, title, processing and privacy status), read only to confirm that an upload succeeded.

The tool does not access data about any other YouTube user or channel. It does not use cookies, analytics or tracking.

How the data is used and stored

The data is used only to upload and schedule the owner's videos and to check their status. The OAuth token is stored in a file on the owner's own computer and is not sent anywhere except to Google's APIs. Channel and video information is read when it is needed and is not stored.

Sharing

No data is sold, shared with or disclosed to any third party.

Deleting data and revoking access

Deleting the local token file removes all stored data. Access can be revoked at any time from the Google security settings page.
